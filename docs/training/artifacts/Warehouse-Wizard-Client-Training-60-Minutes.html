Move or Transfer? Let the warehouse boundary decide

LOCATION MOVE
  • Same warehouse
  • Scan pallet + exact destination
  • Preserves identity + movement history
  • Cancel queued/in-progress move if plan changes
TRANSFER
  • Different warehouse
  • Create → stage → driver sign-off
  • In-transit → destination receive
  • Immediate directed Put-Away
Never strand transferred stock in a receiving lane while the system implies it is stored.
