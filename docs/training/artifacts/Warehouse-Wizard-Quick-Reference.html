Warehouse Wizard — Floor Quick Reference

Product 1.27
IDENTIFY → SCAN → CONFIRM → COMMIT ONCE

RECEIVING

  1. Warehouse · container · PO
  2. Scan/search product; press commit arrow
  3. Total → qty/pallet → pallets
  4. Expiry · lot · packaging
  5. Verify, receive once, print labels

PUT-AWAY

  1. Select task; scan pallet
  2. Scan exact location or select bay cell
  3. Check space, safety, temperature
  4. Place pallet; confirm once
  5. Verify task cleared

WHOLE-PALLET PICK

  1. Travel to assigned cell
  2. Scan exact location / bay selection
  3. Verify condition + full quantity
  4. Scan pallet; confirm highlighted action
  5. Stage in directed lane

MOVE / TRANSFER / COUNT

  • Same warehouse = Location Move
  • Different warehouse = Transfer + driver sign-off
  • Count what you see; submit online
  • Use Inventory Search as the truth check

STOP / ANDON

  • Short or missing pallet
  • Damage, contamination, expiry
  • Unknown barcode
  • Full, blocked, unsafe, wrong-temperature cell
  • Floor and system disagree
  • Device offline

FIVE-STEP RESPONSE

  1. Stop; keep stock safe
  2. Identify pallet, location, task
  3. Verify in Inventory Search
  4. Control status + notify supervisor
  5. Resume once after correction
WW-UM-001 • Normal work: scan-confirm. Exception: stop-verify-control-escalate.

Manager Shift Control

Quick Reference

START OF SHIFT

  1. Choose warehouse + Dashboard view
  2. Review work, people, space, RF
  3. Check holds, quarantine, expiry, reorder
  4. Assign owners
  5. Release finishable work only

END OF SHIFT

  1. Reconcile floor with open queues
  2. Clear/own receiving and staging backlog
  3. Review controlled stock + count variance
  4. Assign unresolved logs
  5. Leave a safe, explicit handoff
